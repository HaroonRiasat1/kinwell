# Storyboards

Each storyboard walks through one real journey in Kinwell, frame by frame. The frames are the
production components rendered with the seeded demo data (the Rahman family), so they stay in
sync with the code — change a component and every storyboard that uses it updates.

| Storyboard | Who | Journey |
| --- | --- | --- |
| Family: weekly check-in | Sana (London) | Sign in → dashboard → alert → lab trend → plan → message |
| Family: move a home visit | Bilal (Dubai) | Visits → 3-step reschedule |
| Parent: ticking off the day | Ammi (Lahore) | Text-code sign in → simple view |
| Nutritionist: a home visit | Hina | Clients → visit form → plan builder → family update |
| Admin: morning review | Zara | Review queue → team → families |
| Onboarding | Sana | Five steps → done |

Screen-by-screen states (loading, empty, error, upload failed, …) are under **Screens**.
